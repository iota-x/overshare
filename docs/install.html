Get it.It's free.

Two minutes, no terminal, no Python. Pick your machine.

You're on this one

macOS

11 Big Sur or later · Apple Silicon & Intel

Download the .dmg

Open it and drag Overshare onto Applications. The first time, right-click the app and choose Open, then confirm — a normal double-click gets refused, because the app isn't signed by a paid Apple developer account. You only do that once.

macOS will ask for Accessibility (window and file titles) and Automation (your browser tab and what's playing) as you go. After granting Accessibility, quit from the menu bar and reopen.

You're on this one

Windows

10 or 11 · 64-bit

Download the installer

Run it. SmartScreen may warn you — click More info, then Run anyway, for the same reason: no paid code-signing certificate. It installs for your user only, so there's no admin prompt.

No permissions to grant, with one exception: if !peek comes back empty, turn on Settings → Privacy & security → Camera → Let desktop apps access your camera.

Then

One link and you're done.

Everything else — the AI, the recaps, what stays private — is optional and already set to something sensible.

One

Open Settings

Click the icon in your menu bar (macOS) or system tray (Windows) → Settings… It opens on a page explaining what the app does.

Two

Paste a webhook

In Discord: right-click a channel → Edit Channel → Integrations → Webhooks → Copy Webhook URL. Paste it into Setup — it goes green when it works. Telegram works too, or both at once.

Three

Nothing

It's already telling her. Take a look at Privacy if you want to add anything to the blocklist — banking, password managers and private windows are hidden already.

Rather build it yourself? Every line is on GitHub, MIT licensed, and the README has the from-source instructions.
